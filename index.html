نسخة أسبوعية تلقائية (Google Drive)

كل خميس 11 مساءً تُحفظ نسخة JSON في مجلد «نسخ احتياطي - مجلس البخاري» على Drive، ويُحتفظ بآخر 12 نسخة، مع سجل في الشيت.

تفعيل/فحص النسخة الأسبوعية

أول مرة فقط: افتح الرابط ووافق على الصلاحيات (Drive + Triggers).

المزامنة منصّبة ومربوطة مسبقاً

مشروع «مزامنة حضور مجلس البخاري» منشور ومربوط بالموقع. لا تحتاج أي خطوة. الكود بالأسفل نسخة احتياطية للرجوع إليها إذا احتجت إعادة النشر.

  1. افتح ملف Google Sheets الخاص بالحضور ← قائمة Extensions ← Apps Script.
  2. امسح الكود القديم بالكامل، والصق الكود الجديد بالأسفل، ثم احفظ.
  3. Deploy ← Manage deployments ← تعديل (قلم) ← Version: New version ← Deploy.
  4. تأكد أن Who has access = Anyone، ثم انسخ رابط الـ Web app والصقه في تبويب المزامنة.
كود Apps Script الجديد

هذا الكود يضيف: قراءة الحالة من الشيت، ورقة «أوقات التسجيل»، ونسخة احتياطية داخل الشيت تُستخدم تلقائياً إذا تلفت الحالة الأساسية.
