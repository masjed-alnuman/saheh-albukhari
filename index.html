—
نسخ محلية تلقائية
—
  1. افتح ملف Google Sheets الخاص بالحضور ← قائمة Extensions ← Apps Script.
  2. امسح الكود القديم بالكامل، والصق الكود الجديد بالأسفل، ثم احفظ.
  3. Deploy ← Manage deployments ← تعديل (قلم) ← Version: New version ← Deploy.
  4. تأكد أن Who has access = Anyone، ثم انسخ رابط الـ Web app والصقه في تبويب المزامنة.
