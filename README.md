## إعداد Google Apps Script

الكود موجود داخل `index.html` (تبويب الإعدادات ← «كود Google»)، ونسخة مستقلة في `apps-script-Bukhari.gs`.

**الطريقة اليدوية:**
1. افتح الشيت ← **Extensions** ← **Apps Script**.
2. امسح الكود القديم والصق الجديد، ثم احفظ.
3. **Deploy** ← **Manage deployments** ← ✏️ ← **Version: New version** ← **Deploy**.
4. تأكد `Who has access = Anyone`.

**الطريقة البرمجية (أدوات المشروع):**
```powershell
python _tools\check_api.py          # هل Apps Script API مفعّل؟
python _tools\oauth_google.py       # موافقة لمرة واحدة (يفتح رابطاً)
python _tools\deploy_apps_script.py # إنشاء/تحديث المشروع ونشره
```
- يجب تفعيل Apps Script API من: https://script.google.com/home/usersettings
- الشيت المستهدف: `سجل حضور مجلس صحيح البخاري`
  (ID: `1xZC_GGDVyBeoIIMVZ5-D_QOrMrDL8j45KTIOdkeYUJk`)

## QR الحضور عند الباب

- زر **«ملصق QR»** يفتح رمزاً واحداً للمجلس كله، مع زر طباعة ملصق A4 جاهز للتعليق.
- رابط الملصق: `https://masjed-alnuman.github.io/saheh-albukhari/?gate=1`
- الطالب يمسحه ← يختار **«تسجيل الدخول»** أو **«تسجيل الخروج»** ← يكتب اسمه أو رقمه ← يختار اسمه ← **إرسال**.
- تظهر له رسالة: «تم تسجيل الدخول ✓» أو «تم تسجيل الخروج ✓» مع المجلس والتاريخ والساعة، والفترة (الأولى/الثانية/الاستراحة)، ومدة البقاء عند الخروج.
- يسجّل الحركة تلقائياً في الشيت عبر نفس المزامنة.
- زر **«مسح QR»** يبقى متاحاً للمشرف لمسح رموز الطلاب الفردية (من بطاقة الطالب ← «رمز QR»).

## الفترتان والوقت الفائت

- كل خميس له **٤ أوقات**: بداية الفترة الأولى، نهايتها، بداية الفترة الثانية، نهايتها. تُضبط من زر الساعة (أو من تعديل الأسبوع)، وتُنسخ تلقائياً من الأسبوع السابق.
- الحضور الأسبوعي يبقى **حاضر/غائب** كما هو، لكن يُضاف تفصيل لكل فترة:
  - من دخل في الفترة الأولى وخرج في الاستراحة تُحتسب له الأولى فقط.
  - من جاء في الاستراحة وبقي تُحتسب له الثانية فقط.
  - من حضر جزءاً من فترة تُحتسب له الفترة، ويُحسب عليه الوقت الفائت.
- **الوقت الفائت** = التأخر عن بداية الفترة + الخروج قبل نهايتها + أي فترة ضائعة كاملة + أي فجوة خروج/عودة داخل الفترة. يُجمع في رقم واحد لكل أسبوع ويظهر في الجدول والبطاقة وسجل الطالب.
- إذا لم يُسجَّل خروج، يُعتبر الطالب باقياً لآخر الفترة الثانية (حضور كامل) مع تنبيه في التفاصيل.
- **تعديل يدوي:** من سجل الطالب ← أيقونة القلم جنب أي أسبوع ← يمكن تعديل وقت الدخول/الخروج، أو كتابة **الوقت الفائت** يدوياً (0 = لا فائت). التعديل اليدوي يتجاوز الحساب التلقائي ويُحفظ مع الطالب.
- **توليد الأسابيع:** زر «توليد أسابيع» يُنشئ كل أيام الخميس بين تاريخين، ويتجاهل الموجود، ولا يسجّل حضوراً لأي طالب.
- الأسابيع القديمة التي ليس لها أوقات فترات تبقى بالحساب القديم (وقت بدء واحد).
- التصدير إلى Excel يحتوي ورقة **«تفاصيل الفترات»** (دخول/خروج/حالة كل فترة/الوقت الفائت).

## المكتبات المحلية (بدون CDN)

كل المكتبات والخطوط والأيقونات موجودة في `vendor/` وتُحمَّل محلياً:
- `vendor/fonts/` — خطوط Tajawal وAmiri.
- `vendor/fontawesome/` — الأيقونات وخطوطها.
- `vendor/qrcode.min.js` + `vendor/jsQR.js` — توليد وقراءة QR.
- `vendor/xlsx.full.min.js` — تصدير Excel.

لا يعتمد الموقع على أي CDN، ويعمل حتى لو انقطع الإنترنت (المزامنة فقط تحتاج اتصالاً).

## كلمة سر الموقع (عامة)

- كلمة سر واحدة تُطلب على **أي جهاز جديد** قبل فتح لوحة الإدارة.
- بعد أول إدخال، يتذكرها الجهاز؛ زر «اقفل الآن» يمسحها ويعيد القفل.
- صفحة تسجيل الحضور `?gate=1` **لا تطلبها**.
- الحفظ في الشيت لا يقبل أي تعديل بدون كلمة السر (حتى لو عرف أحد الرابط).
- لتغيير كلمة السر، تواصل مع المطوّر (تتغير في الكود وعلى السيرفر معاً).

## النسخ الاحتياطي الأسبوعي (تلقائي)

- كل **خميس 11:00 مساءً** (توقيت الشيت) يُنشئ Apps Script ملف **JSON** في Google Drive داخل مجلد «نسخ احتياطي - مجلس البخاري».
- يحتفظ بآخر **12** نسخة ويحذف الأقدم، ويسجّل كل نسخة في ورقة «سجل النسخ الاحتياطي».
- **التفعيل مرة واحدة:** الإعدادات ← النسخ الاحتياطي ← «تفعيل/فحص النسخة الأسبوعية» ← Allow.
- للفحص: `<webhook>?action=status`، ولإنشاء نسخة فوراً: `<webhook>?action=backupnow`.

## مفتاح المزامنة (حماية الشيت)

- اختياري، من: الإعدادات ← المزامنة ← «مفتاح المزامنة» ← **توليد** ← **حفظ**.
- بعد التفعيل، **كل أجهزة المشرفين لازم نفس المفتاح**، وإلا يُرفض رفعها.
- صفحة QR عند الباب **لا تحتاجه** (لها بوابة تسجيل منفصلة تحدّث حضور طالب واحد فقط).
- المفتاح يُخزَّن على كل جهاز محلياً، ولا يُحفظ في الشيت.

## ملاحظات تشغيلية

- البيانات تُحفظ محلياً في `localStorage` أولاً، ثم تُزامن مع Google Sheets.
- إضافة/تعديل الطالب: خانة واحدة للاسم الكامل، والنظام يقسّمه داخلياً للتوافق مع الحالة القديمة.
- ورقة «سجل الحضور التراكمي» تعرض عمود **«الاسم الكامل»** واحداً بدل (الاسم/الأب/الكنية)، وكذلك تصدير Excel/CSV.
- وقت الحضور يُسجَّل تلقائياً عند الضغط على «حاضر».
- أوقات الفترتين تُضبط من زر الساعة (في شريط الأدوات أو رأس عمود الخميس).
- الجدول يعرض لكل أسبوع حالتَي الفترتين (ف1/ف2) والوقت الفائت، ويفصّل سجل الطالب الدخول والخروج.
- الجدول يعرض آخر ١٢ أسبوعاً افتراضياً (يمكن اختيار «كل الأسابيع»)، وكل البيانات محفوظة.
- نسخ احتياطي: نسخ محلية تلقائية + تنزيل JSON + أوراق Excel.
- كود Google يحتفظ بنسخة احتياطية داخل الشيت (`_حالة_المزامنة_نسخة`) ويسترجعها عند تلف الحالة الأساسية.
